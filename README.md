# 🔥 Firefly — Módulo Python

**Algoritmo de análise preditiva para apoio à decisão em operações de resgate emergencial**

Este módulo contém a implementação em Python do Firefly, um algoritmo de análise preditiva que avalia cenários de resgate (bombeiros, SAMU e Defesa Civil) e recomenda ações com base em um Processo de Decisão de Markov (MDP) simplificado.

---

## 📌 Sobre o Módulo

A camada Python é responsável pela modelagem matemática e processamento dos dados do cenário: cálculo de estados, transições, recompensas e definição da política de decisão do MDP simplificado.

Desenvolvido como parte do Global Solution 2026/1 da FIAP.

---

## 🛠️ Tecnologias

- Python
- Modelagem de Processo de Decisão de Markov (MDP) simplificado
- Processamento e análise de dados do cenário de resgate

---

## 🧩 Estrutura

- Definição dos estados possíveis do cenário de resgate
- Cálculo de recompensas e transições entre estados
- Lógica de recomendação da ação ótima a partir da política aprendida

---

## 👥 Equipe

Projeto desenvolvido em equipe de 5 integrantes, com este módulo focado na modelagem preditiva e cálculo do MDP em Python.
